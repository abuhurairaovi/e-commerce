# Sellio - Full-Stack Web Application

This is a full-stack web application built with **Next.js** (Frontend) and **Node.js / Express** (Backend), using **PostgreSQL** for the database, **JWT** for secure authentication, and Nodemailer for email notifications.

---

## Prerequisites

Make sure you have installed the following on your system:
- [Node.js](https://nodejs.org/) (v18 or higher)
- [PostgreSQL](https://www.postgresql.org/)

---
